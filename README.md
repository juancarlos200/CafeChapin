Declaración de IA:

Se utilizó Inteligencia Artificial (IA) únicamente como herramienta de apoyo durante el desarrollo de este laboratorio. Su uso se limitó a resolver dudas relacionadas con Android Studio, consultar y comprender aspectos de la sintaxis de Kotlin, aclarar conceptos y errores encontrados durante el desarrollo, y facilitar una mejor comprensión de las instrucciones y objetivos del laboratorio. También se usó para la redacción de esta declaración.

La IA no fue utilizada para generar o escribir el código de la solución. La implementación, estructura y decisiones tomadas en el desarrollo del código fueron realizadas por nosotros, estudiantes representantes del grupo 2JH, utilizando la IA únicamente como recurso de consulta y orientación.
